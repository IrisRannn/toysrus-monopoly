# 手机横屏体验窗口

## 入口与试用

- 玩家：`/player-preview`，填写昵称和所属队伍后加入，推荐手机横屏。
- 主持人：`/host-preview`，进入体验控制台后，先在“固定投骰代表”为各队选择已加入的员工，再开始游戏。
- 大屏：主持人仍可打开`/screen?room=261219`，声音继续只由大屏播放。

体验入口固定连接261219，忽略链接中其他房间号，避免误入正式房间。首次玩家加入或主持人进入会自动建立体验房间，默认内置19题和正式BGM。正式261218的队员、身份、题目修改、答题记录、代表名单及进度与体验房间分别保存在各自房间快照中。试用不会修改正式房间设置；正常入口及二维码继续使用原玩家界面，体验房间二维码指向体验页。

## 界面

横屏时左侧完整显示现有16:9原图及实时棋子、中央骰子和特殊格卡片，右侧显示当前回合、五队进度及当前需要的操作。普通玩家没有投骰或申请代表按钮；只有当前队伍指定代表能看到投骰按钮。上海SSC保留现场实体骰子，由主持人录入。手机页面不加载音频或嵌套大屏页面。

本队开始答题时自动弹出原玩家端共用的答题组件，保留截止、改答及每人一份答案规则。提交成功后关闭窗口，截止前可点击“已提交…修改答案”重新打开；揭晓后可查看结果并返回棋盘。其他队伍继续观看。奖励卡片与移动期间让棋盘可见，之后显示本队答题结果。

横屏弹窗选项排为两列，竖屏为一列，窗口内容过长时可滚动；竖屏页面有横屏提示，仍能正常答题。支持的浏览器显示全屏按钮，不强制锁定手机方向。

## 主持人指定代表

体验房间默认开启“投骰代表仅由主持人指定”。主持人可预先设置四支线上队伍的固定代表，后续回合和重置游戏沿用名单。名单指向已加入员工的会话ID，请先核对实际员工。员工被移除或转队时自动清除失效指定。

本队投骰前及回合结束后可以更换；投骰、移动或答题过程中锁定本队名单，其他队伍仍可预先安排。名单变更会清除待撤销操作，避免撤销恢复失效代表。服务器同时拦截自荐、伪装为指定命令、替他人设置名单及非指定员工投骰，权限不依赖按钮是否显示。

原房间默认保留原有代表申请方式，现有房间无需迁移。主持人也可以单独开启该设置，采用相同的指定规则。设置、名单及当前回合代表写入房间快照，无需增加数据库表。

## 切回与数据

体验页右下角“原玩家界面”使用同一房间、同一员工身份打开原布局，可通过“返回横屏体验”回来，不重复加入。261219开启主持人指定模式时，原布局也不会出现自荐按钮；两种界面遵守同一服务器权限。

原正式入口`/player?room=261218`和`/host?room=261218`保留。体验身份不覆盖浏览器记住的正式房间或正式凭证。源码回退基线为提交`4cc73e8`；切换界面本身无需回退代码或重置游戏。

房间隔离与固定号码不改变存储条件：Render免费实例的临时文件在重新部署或实例更换后可能丢失。保留进度仍需要持久化数据库及上传文件目录；此体验功能没有开通付费资源或连接新的云服务。

## 验证

先构建，再在一个终端启动`NODE_ENV=production node tests/slow-server.mjs`，另一个终端执行`python tests/browser.py`和`python tests/preview-browser.py`。脚本校验隔离服务标记，禁止对真实活动房间运行。覆盖原三端完整流程，以及横屏/竖屏、固定代表、回合自动沿用、服务端权限、弹窗作答与改答、切回原布局及正式房间状态隔离。专用PostgreSQL和1500人容量验收另行进行。
