# 正式横屏游戏 · 房间261219

原261219横屏测试版本已被选为正式游戏。默认年会房间、首页入口和主持人二维码均指向261219。

## 入口与原有数据

- 玩家：`/player?room=261219`，手机横屏观看完整棋盘。
- 主持人：`/host?room=261219`。
- 大屏：`/screen?room=261219`。
- 兼容入口：`/player-preview`和`/host-preview`仍固定连接261219，不再创建另一套测试状态。
- 简洁玩家布局：`/player-classic?room=261219`，沿用同一身份和房间；可以返回棋盘界面。
- 原房间261218保留独立状态，仍可通过显式房间链接访问。代码更新不重置任一房间；默认入口不会因浏览器曾记住261218而误入旧房间。

首次进入261219会建立房间，已有房间再次进入保留队伍、题库、代表及游戏进度。261219沿用原测试版的“主持人指定代表”规则。未产生代表时显示“等待东区产生代表”等当前区域提示；只有指定代表可在本队回合投骰。上海SSC保留实体骰子、主持人录入规则。

## 全员观看记忆大考验

任一队伍开始记忆大考验或终极周年挑战后，所有队伍的手机自动弹出题目，展示本次答题队伍、已提交人数／可答题人数和A/B/C/D各选项实时选择人数。大屏同步展示相同汇总数据。

仅当前触发题目的队伍可以选择并提交答案。其他队伍只能观看，页面不提供提交按钮；通过HTTP或实时连接伪造答案同样会被服务器拒绝。当前队伍可在截止前改答：更换选项会减少原选项人数、增加新选项人数，总提交人数不重复累计。提交成功后窗口保持打开，便于继续查看实时进度；任何人都可手动关闭并重新打开。

暂停或截止后不可继续提交；恢复后依照服务器保存的截止时间处理。个人答题记录仅主持人可查看，玩家只接收自己的答案和汇总人数。正确答案、解析在主持人揭晓后公开，提前公开的票数不会包含答案标记。

横屏弹窗为双列选项，竖屏为单列；较长题目可以在弹窗内部滚动。棋盘移动和特殊格展示期间回到棋盘，之后可继续查看答题结果。

## 音乐和音效

继续使用内置正式BGM、摇骰、脚步和特殊格提示音。主持人控制是否播放BGM、音效开关和音量。大屏每次打开需点击“开启大屏声音”；员工手机默认静音，可点击“开启手机声音”播放，也可单独静音，不影响其他设备。手机刷新后重新手动开启，避免现场自动大范围出声。

BGM在主持人启用后播放，动作时自动降低背景音乐音量。未开启手机声音时不主动播放音乐，音效由浏览器本地合成。上传的音乐与棋盘仍需要持久化存储。

## 本地验收

```bash
npm ci
npm test
npm run lint
npm run build
# 单独安装Playwright及其浏览器后运行；脚本只启动临时本机游戏。
node tests/anniversary-browser.mjs
```

可使用`PLAYWRIGHT_MODULE`指定Playwright模块，`BROWSER_EXECUTABLE`指定本机Chromium浏览器，`BROWSER_OUTPUT`指定截图目录。浏览器测试覆盖默认房间和兼容入口、各队观看、当前队伍作答、实时改答计数、跨队伪造请求、截止和揭晓、声音默认关闭与独立开启，以及横竖屏布局。它不会连接Render或真实活动房间。

原`tests/browser.py`为简洁布局的旧回归脚本，原`tests/preview-browser.py`为正式化前的隔离体验脚本；当前正式版本使用`tests/anniversary-browser.mjs`验收。1500人容量仍需单独压测。

Render免费实例仍使用临时文件系统。重新部署可能丢失旧数据库和上传文件；代码层面保留房间不等于平台会保留文件，发布前需确认数据备份或迁移安排。
