# 周年内置题库来源

`anniversary-questions.json`来自用户在2026年11月3日提供的《互动问答20题_模板格式.xlsx》，不是生成的品牌知识题。

- 原表有20个问题行，第13、15题的题干、选项、答案完全相同。保留第13题，合计19道不同问题。
- 原表`tile`列为连续1–20题号，并非有效答题格编号。转换为`tile: 0`，让04/08/12/15/16共用同一题池。
- 第4题的B/C/D选项以Excel日期序列38930/38991/39052保存，分别对应2006-08-01、2006-10-01、2006-12-01。依题目年月格式转换为“2006年8月”“2006年10月”“2006年12月”，正确答案仍为D。
- 其余题干、选项和答案保持原表内容，未补造第20道题。稳定ID以题干的SHA-256摘要生成。

这些文件随服务器代码部署，由服务器读取；前端没有导入本目录。新房间自动得到独立题库副本，后台修改不会影响其他房间。既有房间按`questionBankVersion`一次性补充，保留自定义题目及历史使用记录。

整场已用记录保存在房间数据库中；身份按规范化题干计算，跨格、换ID、空白/标点变化与重排选项都不会让已用问题重新可抽。明确重置整场后才允许在新一局再次使用。
